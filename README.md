# Tienda online Wizard Tech

Tienda en linea para Wizard Tech 

## Descripción del Proyecto
Aplicación web de comercio electrónico desarrollada como proyecto práctico de **React**. Permite a los usuarios explorar un catálogo de productos, filtrar por categorías, visualizar el detalle de cada artículo y gestionar un carrito de compras de forma dinámica.

## Tecnologías Utilizadas
* **React** – Librería principal para la construcción de la interfaz de usuario basada en componentes.
* **Vite** – Entorno de desarrollo y empaquetador rápido.
* **JavaScript (ES6+)** – Lógica de la aplicación y manejo de datos.
* **HTML5 & CSS3** – Estructura semántica y estilos de la aplicación.

## Instalación y Ejecución Local

Sigue estos pasos para clonar y correr el proyecto en tu computadora:

1. **Clonar el repositorio:**

   ```bash
   git clone (https://github.com/alan8723/e-comerc-Wizard-tech.git)
   ```

2. **Instalar dependencias:**

   ```bash
   npm install
   ```

3. **Ejecutar la aplicación:**

   ```bash
   npm run dev
   ```
